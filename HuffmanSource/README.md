What kinds of file lead to lots of compressions? 
Big files with lots of repeating text had lots of compression whereas files with very little 
repetition weren't as compressed and it could also take more space to store the file as compressed 
compared to the original.


What kind of files had little or no compression? 
Small files had little compression or sometimes expansion because by adding the header, they got
bigger.


What happens when you try and compress a huffman code file?
It compresses, unless the huffman code file is already small, in which case it is too small for
further compression.
